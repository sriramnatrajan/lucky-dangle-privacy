# Lucky Charm Widget — Privacy Policy

Public privacy policy for the Android app **Lucky Charm Widget** (`com.luckydanglecharm.android`).

Live page:

https://sriramnatrajan.github.io/lucky-dangle-privacy/

Use that URL in Google Play Console → App content → Privacy policy, and as the privacy policy URL in the AdMob app settings.

The page covers on-device charm settings, Firebase Analytics and Crashlytics, and Google AdMob banner ads inside the app. The hanging charm does not show ads.

To enable Pages: Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save.
